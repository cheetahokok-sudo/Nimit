# App Store listing copy — นิมิต

The exact text in App Store Connect, kept here so the published page and the
repository cannot quietly disagree. Edit this, then paste; never the reverse.

## Why this file exists at all

The first listing was rejected. 1.0.0 (10) went out on 2026-07-30 as:

- **Name** — `นิมิต Nimit - ฝัน ดวง ตรวจหวย`
- **Keywords** — `ทำนายฝัน,ตำราฝัน,พรหมชาติ,ทักษา,นักษัตร,ราศี,โหราศาสตร์,สลากกินแบ่ง,ผลรางวัล,งวด,ความเชื่อ,ตำราโบราณ`

and came back under **guideline 4.3(b) — Design: Spam**, on the finding that the
app "primarily features astrology, horoscopes, palm reading, fortune telling or
zodiac reports". That keyword list is close to a confession: `ทำนายฝัน`
(dream **prediction**), `โหราศาสตร์` (astrology), `ราศี` (zodiac sign) — three
of the exact categories the guideline names, with the app's own name leading on
`ดวง`. The listing described the genre. It did not describe the product.

The product is a **cited reference library**: a corpus of Thai ตำรา where every
reading carries a trust tier, a citation and its original text, plus a checker
for published สลากกินแบ่งรัฐบาล results. That is what the copy below says.

Two rules for anyone editing this file:

1. **Never lead with `ทำนายฝัน`, `โหราศาสตร์`, `ราศี`, or `ดวง`.** Not as a
   euphemism policy — those words genuinely misdescribe an app whose readings
   are sourced and whose almanac screen computes rather than predicts.
2. **Never claim a feature is absent when it is present.** ปฏิทินจันทรคติ and
   กระแสปีนี้ are still in the app, off the tab bar. The copy is allowed to lead
   with the corpus; it is not allowed to pretend the rest is gone.

## Name (30 max)

```
นิมิต Nimit คลังตำรา ตรวจหวย
```

28 characters. `คลังตำรา` (reference library) replaces `ฝัน ดวง`; `Nimit` stays
so a romanised search still lands.

## Subtitle (30 max)

```
ตำราอ้างอิง ตรวจผลสลาก
```

22 characters. The slot was **empty** in the rejected submission — a wasted
30-character field on the one surface that had to argue the app was not generic.

## Keywords (100 max)

```
ตำราฝัน,พรหมชาติ,ตำราโบราณ,คลังตำรา,อ้างอิง,สลากกินแบ่ง,ตรวจหวย,ผลรางวัล,งวด,ความเชื่อไทย,หวย
```

93 characters. Removed: `ทำนายฝัน`, `โหราศาสตร์`, `ราศี`, `นักษัตร`, `ทักษา`.
The last two are almanac vocabulary rather than horoscope vocabulary, but they
read as zodiac terms to a classifier and they are not worth the risk. Kept:
`พรหมชาติ`, because it is the name of a specific text this app transcribes, and
that specificity is the argument.

## Promotional text (170 max)

```
คลังตำราไทยที่ทุกคำแปลบอกที่มาได้ ค้นสัญลักษณ์จากตำราพรหมชาติและตำราฝัน อ่านข้อความต้นฉบับ พร้อมตรวจผลสลากกินแบ่งรัฐบาลจากประกาศจริง
```

## Description

```
นิมิตคือคลังอ้างอิงตำราไทย ไม่ใช่แอปทำนาย

ความต่างของนิมิตอยู่ที่การอ้างอิง ทุกความหมายในแอปนี้ผูกกับตำราที่ระบุชื่อ ระบุชั้นความน่าเชื่อถือ และแสดงข้อความต้นฉบับให้อ่านเทียบได้ ถ้าคลังยังไม่มีตำรารองรับ นิมิตจะบอกว่าไม่มี ไม่แต่งความหมายขึ้นเอง

คลังตำรา
ค้นสัญลักษณ์ด้วยคำเดียว เช่น นก ช้าง น้ำ ทอง แล้วอ่านสิ่งที่ตำราเขียนไว้จริง แต่ละรายการมาพร้อมป้ายชั้นความน่าเชื่อถือ ชื่อตำราที่อ้างอิง และข้อความต้นฉบับ คำที่ยังไม่มีในคลังจะแสดงว่ายังไม่พบ พร้อมบอกว่าคลังกำลังเติบโต

แหล่งอ้างอิง
หน้าแยกที่อธิบายว่าตำราแต่ละชั้นหมายถึงอะไร ความหมายที่ยืนยันด้วยตำราสองเล่มต่างกันไม่เท่ากับความหมายที่พบในเล่มเดียว และแอปแสดงความต่างนั้นให้เห็น มีลิงก์ไปหอสมุดแห่งชาติสำหรับผู้ที่ต้องการตรวจตำราที่ต้นทาง นิมิตไม่ได้รับการรับรองจากหอสมุดแห่งชาติ

ตรวจหวย
ตรวจผลสลากกินแบ่งรัฐบาลจากประกาศจริง ดูรางวัลทุกประเภท เก็บเลขที่สนใจไว้ตรวจอัตโนมัติในงวดถัดไป และย้อนดูผลงวดก่อน ถ้าประกาศยังออกไม่ครบ แอปจะบอกว่ายังไม่ครบ ไม่สรุปผลแทน

ความฝัน
เล่าความฝันเป็นข้อความ แอปจะชี้ไปที่สัญลักษณ์ในคลังตำราที่ตรงกับเรื่องที่เล่า พร้อมที่มาของทุกคำแปล และสร้างการ์ดแชร์ได้โดยไม่ต้องแสดงชื่อหรือข้อมูลเกิด

ปฏิทินจันทรคติ
แปลงวันเกิดเป็นวันทางจันทรคติไทย พร้อมทักษาและนักษัตรตามที่ตำรากำหนด เป็นการคำนวณปฏิทินและการอ้างอิงตำรา ไม่ใช่คำทำนาย

ความเป็นส่วนตัว
ไม่ต้องสมัครสมาชิก ไม่ต้องเข้าสู่ระบบ ใช้ได้ทุกฟังก์ชันทันที ความฝันที่บันทึก วันเกิด และเลขที่เก็บไว้ อยู่ในเครื่องของคุณ ไม่ถูกส่งออก

หมายเหตุ
นิมิตเป็นแอปด้านความเชื่อและวัฒนธรรมไทย เนื้อหาในแอปเป็นการรวบรวมและอ้างอิงตำรา ไม่ใช่คำแนะนำทางการเงิน การลงทุน หรือทางการแพทย์ และไม่รับประกันผลรางวัล การเสี่ยงโชคมีความเสี่ยง โปรดใช้วิจารณญาณ
```

## Screenshots

**The 7 screenshots on the rejected submission are now wrong.** They show the
old five-tab bar with `ดวง` and `กระแส` in it. Leaving them up would put the
rejected structure on the product page while the reply to App Review argues the
app has been repositioned — the single most obvious way to earn a second
rejection.

New shots must come from a build of the repositioned app, and must show, in
order: คลังตำรา search with results and tier badges; a symbol story with its
citation and original text; แหล่งอ้างอิง with the tier explanations;
ตรวจหวย with a real draw; the dream flow.
